- Showcase AI capabilities

## 🤖 Module 2: AI Agent Engine

**File:** `ai_agent.py`  
**Purpose:** Core conversational AI with multi-modal capabilities  
**Model:** OpenAI GPT-4o-mini (or specified model)

### Core Capabilities
1. **Document Understanding** (PDF, DOCX, TXT)
2. **Image Analysis** (OCR + Vision AI)
3. **Conversational Memory** (RAG with ChromaDB)
4. **Tool Use** (Function calling, API integration)
5. **Safety Guardrails** (Dynamic content filtering)

### Agent Architecture
```python
class GenericAIAgent:
    """
    Modular AI agent for rapid hackathon deployment
    """
    def __init__(self, config_path: str):
        self.system_prompt = self.load_prompt(config_path)
        self.guardrails = self.load_guardrails(config_path)
        self.tools = self.load_tools()
        self.memory = VectorMemory()
    
    def process_query(self, user_input: str):
        # 1. Guardrail check
        if not self.guardrails.validate(user_input):
            return self.guardrails.get_response()
        
        # 2. Retrieve relevant context
        context = self.memory.retrieve(user_input)
        
        # 3. Tool selection (if needed)
        tools = self.select_tools(user_input)
        
        # 4. Generate response
        response = self.llm.generate(
            system=self.system_prompt,
            user=user_input,
            context=context,
            tools=tools
        )
        
        # 5. Update memory
        self.memory.store(user_input, response)
        
        return response
```

## 🗄️ Module 3: Local Database System

**File:** `use_case_database.py`  
**Purpose:** Lightweight, zero-setup data storage  
**Technology:** SQLite (built into Python)

### Why SQLite for Hackathons?
✅ No installation required  
✅ Single file database  
✅ SQL support  
✅ Fast for demos  
✅ Easy to reset/modify

### Database Architecture

```python
# use_case_database.py

import sqlite3
from pathlib import Path

class UseCaseDatabase:
    """
    Generic database handler for any use case
    """
    def __init__(self, db_path: str = "use_case.db"):
        self.db_path = db_path
        self.conn = sqlite3.connect(db_path)
        self.cursor = self.conn.cursor()
    
    def create_schema(self, schema_sql: str):
        """Execute SQL schema definition"""
        self.cursor.executescript(schema_sql)
        self.conn.commit()
    
    def query(self, sql: str, params: tuple = ()):
        """Execute SELECT query"""
        self.cursor.execute(sql, params)
        return self.cursor.fetchall()
    
    def execute(self, sql: str, params: tuple = ()):
        """Execute INSERT/UPDATE/DELETE"""
        self.cursor.execute(sql, params)
        self.conn.commit()
        return self.cursor.lastrowid
```

### Database Integration with AI Agent

```python
# In ai_agent.py

from use_case_database import UseCaseDatabase

class GenericAIAgent:
    def __init__(self, db_path: str):
        self.db = UseCaseDatabase(db_path)
        # ... other initialization
    
    def query_database(self, natural_language_query: str):
        """
        Convert natural language to SQL and execute
        """
        # Use LLM to generate SQL from natural language
        sql_query = self.llm.generate_sql(
            query=natural_language_query,
            schema=self.db.get_schema()
        )
        
        # Execute with safety checks
        if self.validate_sql(sql_query):
            results = self.db.query(sql_query)
            return self.format_results(results)
        else:
            return "I cannot execute that query safely."
```

### Loading Configuration at Runtime

```python
# config.py

class DynamicConfig:
    @staticmethod
    def load_for_use_case(use_case: str):
        """
        Load configuration based on use case identifier
        """
        config_file = f"configs/{use_case}/SYSTEM_PROMPTS.md"
        
        with open(config_file, 'r') as f:
            content = f.read()
        
        # Parse sections
        config = {
            'system_prompt': extract_section(content, 'Full Prompt'),
            'guardrails': extract_section(content, 'Guardrail Response'),
            'prohibited': extract_list(content, 'Prohibited Patterns'),
            'allowed': extract_list(content, 'Allowed Operations')
        }
        
        return config
```

## 🚨 Guardrails Configuration

### Safety Levels

#### Level 1: Permissive (Public demos)
```python
PROHIBITED_PATTERNS = [
    "illegal", "harmful", "dangerous", "weapon"
]
```

#### Level 2: Standard (Most use cases)
```python
PROHIBITED_PATTERNS = [
    "hack", "exploit", "illegal", "harmful", "dangerous",
    "weapon", "drug", "violence", "fraud", "scam"
]
```

#### Level 3: Strict (Sensitive domains)
```python
PROHIBITED_PATTERNS = [
    # All Level 2 patterns +
    "diagnose", "prescribe", "investment advice",
    "legal advice", "tax advice", "bypass", "override"
]
```

### Custom Guardrail Functions

```python
# guardrails.py

def check_medical_guardrails(query: str) -> bool:
    """Specific to healthcare use cases"""
    medical_prohibited = [
        "diagnose me", "what medication", "prescribe",
        "instead of seeing a doctor"
    ]
    return not any(p in query.lower() for p in medical_prohibited)

def check_financial_guardrails(query: str) -> bool:
    """Specific to financial use cases"""
    financial_prohibited = [
        "guaranteed returns", "invest all", "sure thing",
        "can't lose", "tax evasion"
    ]
    return not any(p in query.lower() for p in financial_prohibited)
```

## 🔧 Troubleshooting Guide

### Common Issues & Fixes

#### Issue: API Rate Limits
**Solution:** Implement exponential backoff
```python
import time
from openai import RateLimitError

def api_call_with_retry(func, max_retries=3):
    for i in range(max_retries):
        try:
            return func()
        except RateLimitError:
            wait_time = 2 ** i
            time.sleep(wait_time)
    raise Exception("Max retries exceeded")
```

#### Issue: Slow First Response
**Solution:** Warm-up the model on launch
```python
# On app startup
def warmup():
    agent.process_query("Hello")  # Dummy query
```

#### Issue: Database Lock
**Solution:** Use WAL mode for SQLite
```python
conn.execute("PRAGMA journal_mode=WAL")
```
